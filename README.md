# RabTech Task 5 — Deep Learning / NLP Text Classifier

## Project
**IMDB Sentiment Classification using TensorFlow / Keras**

This project implements Task 5 as a genuine NLP text-classification pipeline.

### Task 5 requirements covered

- Text tokenization and vectorization using Keras `TextVectorization`
- Multi-layer neural network
- Embedding layer
- Batch Normalization
- Dropout
- EarlyStopping callback
- ReduceLROnPlateau callback
- Training and validation
- Loss convergence curve
- Accuracy convergence curve
- Unseen custom text inference
- Classification confidence
- Test metrics and confusion matrix
- Saved trained model and reproducibility artifacts

## Run

Open `05_deep_learning_nlp_text_classifier.ipynb` in Jupyter or Google Colab and run all cells from top to bottom.

The first cell installs the required Python packages.

## Expected submission proof

The final notebook should visibly contain:

1. model architecture/summary
2. training output
3. loss curve
4. accuracy curve
5. unseen sample inference table
6. classification confidence
7. test metrics
8. final Task 5 checklist
